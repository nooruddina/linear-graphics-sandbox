Linear Algebra Graphics Sandbox
This was just me messing around with computer graphics& OpenGL while going through my linear algebra course.

I was experimenting with transformations (like scaling, rotating, and translating objects), basic shaders, camera movement, and seeing how it all comes together. It’s not polished or organized — more like a learning sandbox where I tried out stuff I was curious about.

The code gets messy in places, and things aren’t really structured like a final project, because it isn’t. I just wanted to try things out and see what worked. Still, I thought it might be worth putting out there in case anyone finds it interesting or helpful.

Stuff I explored:
2D and 3D rendering with OpenGL

Writing basic vertex and fragment shaders

Playing around with matrices using GLM (translation, scaling, etc.)

Some camera controls and input handling

Note: A lot of the comments in the code were just me trying to explain things to myself while I was learning — some of them might sound weird or overly detailed. I left them in because they reflect how I was thinking through the concepts at the time.
